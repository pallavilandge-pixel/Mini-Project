# Mini-Project
AI-Powered Cybersecurity

This project focuses on improving online security using cybersecurity concepts and AI-based analysis. It identifies common security risks and provides suitable solutions to protect user accounts and personal information.

The project consists of four main tasks:
1. Student Account Security: Identifies account security risks and suggests strong passwords, multi-factor authentication (MFA), and regular software updates.
2. Phishing Email Detection: Identifies suspicious emails and explains how to recognize fake messages and avoid online scams.
3. Sign-in Alert Analysis: Examines login records to detect unusual activities and possible unauthorized access.
4. Evaluation of AI-Generated Security Advice: Checks AI-generated security recommendations for errors and provides safer, more accurate advice.
